## Shape Idea

Before starting AISDD discovery, check `ideas/active/`. If an implementation request names exactly one active idea, create `specs/<slug>/`, then promote the idea to `ideas/promoted/` with reciprocal links. Do not promote ambiguous ideas automatically. Use `$shape-idea` to create, extract, refine, or discard ideas.
