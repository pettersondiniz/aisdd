# Project guidance

## AISDD

For software features, fixes, refactors, migrations, architecture, and related
technical changes, use `$aisdd-lite` and read its `instructions.md` before
working. That file is the single source of truth for triage, V2 → V1 → solo
subagent fallback, model routing, artifacts, validation, and completion.

Follow an explicit user request to skip AISDD or work without delegation.
Keep project-specific commands and constraints in this `AGENTS.md`.
